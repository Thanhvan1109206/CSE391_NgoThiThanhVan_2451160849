# Tier 0 Answers

## File .jsx khác gì file .js?

- File .js chứa JavaScript thông thường.
- File .jsx cho phép viết JSX (cú pháp giống HTML bên trong JavaScript).

## Tại sao phải export default App?

Để component App có thể được import và sử dụng ở file khác.

## Điều gì xảy ra nếu xóa export default App?

React/Vite sẽ báo lỗi vì không tìm thấy component App để render.
